このアプリで使っている htmx の要素

1 属性4点セット

htmx の基本は「いつ・どこへ・どこに・どう入れるか」の4つだけ。ほぼ全部これの組み合わせ。

hx-get="/companies/"     ← どこへ（メソッドと URL）
hx-trigger="click"       ← いつ
hx-target="#results"     ← どこに
hx-swap="outerHTML"      ← どう入れるか

2 ライブ検索

changed で「値が変わったときだけ」、delay:350ms で「打ち終わってから」。この2語で無駄なリクエストが消える。

hx-trigger="keyup changed delay:350ms"

👉 取引先一覧 の検索窓

3 クリックしてその場で編集

1本の URL が「表示用HTML」と「編集フォーム」を出し分ける。状態はサーバだけが持つ。

表示 --click--> GET ?edit=1 --> フォーム
フォーム --submit--> POST   --> 表示

👉 取引先の詳細ページで、電話番号などをクリック

4 モーダル

標準の <dialog> を空で置いておき、htmx が中身を差し込む。保存成功時はサーバが 204 No Content ＋ ヘッダで「閉じろ」と指示する。

HX-Trigger: {"closeModal": {}, "toast": {...}}

👉 どのページでも「＋ 新規」ボタン

5 Out of Band Swap

1レスポンスで画面の離れた複数箇所を更新する。返す HTML に混ぜておくだけ。

<span id="task-badge" hx-swap-oob="true">3</span>

👉 タスクのチェックを付けると、行とサイドバーのバッジが同時に変わる

6 イベントによる疎結合

「モーダルが一覧を更新する」と書くと密結合になる。サーバがイベント名を投げ、一覧は自分で自分を更新する形にする。

サーバ: HX-Trigger: {"companyListChanged": {}}
一覧:   hx-trigger="companyListChanged from:body"

7 無限スクロール

最後の要素に revealed。スクロール監視のコードは書かない。

hx-trigger="revealed" hx-swap="beforeend"

👉 活動履歴を下までスクロール

8 ポーリングと遅延ロード

hx-trigger="every 30s"  ← 定期更新
hx-trigger="load"       ← 表示直後に1回だけ

👉 ダッシュボードの KPI とパイプライン

その場で試す

hx-indicator：通信中だけ表示される要素を指定する。ボタンを押すと 1.5 秒かかるエンドポイントを叩く。

待っています… {% partialdef slow-result inline %}
サーバ時刻: {{ now|date:"H:i:s" }}（ボタンを押すと更新されます）
{% endpartialdef %}

hx-confirm：送信前に確認ダイアログを出す。

hx-swap のタイミング指定：CSS トランジションと組み合わせる。

hx-swap="outerHTML swap:300ms"

Django 6.1 側のポイント

テンプレートパーシャル

Django 6.0 で標準搭載。フルページ用とhtmx断片用でテンプレートを2つに分けなくてよくなった。

{% templatetag openblock %} partialdef results inline {% templatetag closeblock %}
  <div id="results">…</div>
{% templatetag openblock %} endpartialdef {% templatetag closeblock %}

# views.py
render(request, "crm/company_list.html#results", ctx)

querystring タグ

Django 5.1 で追加。今の GET パラメータを保ったまま一部だけ差し替えた URL を作る。ページングとソートに必須。

{% templatetag openblock %} querystring page=page_obj.next_page_number {% templatetag closeblock %}

django-htmx

ミドルウェアが request.htmx を生やす。ヘッダを直接触らずに済む。

if request.htmx:
    return render(request, "list.html#rows", ctx)

trigger_client_event(response, "toast", {...})
return HttpResponseClientRedirect("/companies/")

CSRF

body に一度書けば全リクエストに乗る（属性は子要素に継承される）。

<body hx-headers='{"X-CSRFToken": "…"}'>
